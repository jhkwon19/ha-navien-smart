# Navien Airone for Home Assistant

Home Assistant에서 경동나비엔 **제습환기청정기**를 연동하기 위한 비공식 커스텀 통합 구성요소입니다.

현재는 국내 나비엔 스마트 앱 계정 기반으로 동작하며, 검증된 제품군만 지원합니다.

## 지원 범위

현재 확인된 지원 대상은 아래 조합입니다.

- 제품군: 제습환기청정기
- 서비스 코드: `300`
- 룸콘/컨트롤러
  - `NRT-530S3`, 모델 코드 `1900`, 룸콘 내장센서형
  - `NRT-530Z3`, 모델 코드 `1901`, 별도 에어모니터 연동형
- 확인된 에어모니터
  - `NAA-30DM`, 모델 코드 `34`, 라돈플러스
  - `NAA-21DM`, 모델 코드 `35`

같은 계정에 다른 제품군이 있어도 통합 구성요소는 해당 장치를 등록하지 않습니다. NRT530/NRZ530 계열로 식별되는 장치는 등록을 시도하며, 미확인 모델은 진단정보를 통해 지원 범위를 보완합니다.

## 제공 기능

- 나비엔 스마트 계정 로그인
- 장치 자동 검색
- 전원 ON/OFF
- 현재 운전 상태 조회
- 운전 모드 선택
  - 자동
  - 환기제습
  - 환기
  - 제습
  - 청정
  - 요리
  - 숙면
  - 바이패스
- 모드별 풍량/옵션 선택
  - 자동
  - 미풍
  - 약풍
  - 강풍
  - 터보
  - 절전
  - 기저
- 제습 모드 목표 습도 설정
  - 40% ~ 65%
  - 5% 단위
- 실내 공기질 센서
  - 온도
  - 습도
  - PM1.0
  - PM2.5
  - PM10
  - CO2
  - TVOC
  - 통합 공기질 점수
- 별도 에어모니터가 연결된 경우 Home Assistant 장치 정보에 별도 센서 장치로 표시

라돈 센서는 실제 응답에 라돈 값이 확인되는 장비에서만 생성되도록 준비되어 있습니다. 현재 `NAA-21DM` 조합에서는 라돈 센서가 생성되지 않는 것이 정상입니다.

## 설치 방법

### HACS로 설치

HACS에서 커스텀 저장소로 추가해서 설치할 수 있습니다.

1. HACS를 엽니다.
2. 오른쪽 위 메뉴에서 `Custom repositories`를 선택합니다.
3. 저장소 주소를 입력합니다.

```text
https://github.com/jhkwon19/ha-navien-smart
```

4. Category는 `Integration`을 선택합니다.
5. 추가 후 `Navien Airone`을 설치합니다.
6. Home Assistant를 재시작합니다.
7. `설정 > 기기 및 서비스 > 통합 구성요소 추가`에서 `Navien Airone`을 추가합니다.

### 수동 설치

1. 이 저장소를 내려받습니다.
2. Home Assistant 설정 폴더 아래에 `custom_components/navien_smart` 폴더를 복사합니다.

예시:

```text
config/
  custom_components/
    navien_smart/
      manifest.json
      __init__.py
      ...
```

3. Home Assistant를 재시작합니다.
4. `설정 > 기기 및 서비스 > 통합 구성요소 추가`에서 `Navien Airone`을 검색합니다.
5. 나비엔 스마트 앱에서 사용하는 아이디와 비밀번호를 입력합니다.

## 주의사항

이 통합 구성요소는 경동나비엔에서 제공하는 공식 연동이 아닙니다.

나비엔 스마트 앱의 서버 정책에 따라 같은 계정을 앱과 Home Assistant에서 동시에 사용할 때 앱 로그인 세션이 해제될 수 있습니다. 이 문제는 통합 구성요소 코드만으로 완전히 보장하기 어렵습니다.

가능하면 아래 방식 중 하나를 권장합니다.

- Home Assistant 전용 나비엔 계정 사용
- 앱 사용 빈도가 낮은 계정 사용
- 장시간 사용 후 상태 반영과 세션 유지 여부 확인

## 지원하지 않는 항목

- 보일러
- 숙면매트
- 스마트홈/월패드
- 상업용 SCADA
- 검증되지 않은 환기청정/제습환기청정기 모델
- 로컬 IP 직접 제어

로컬 통신 방식은 별도 실험 단계이며 이 공개 배포본에는 포함하지 않습니다.

## 로그

문제가 있을 때만 아래처럼 debug 로그를 켜서 확인할 수 있습니다.

```yaml
logger:
  default: info
  logs:
    custom_components.navien_smart: debug
```

민감한 계정 정보, 토큰, APK 분석 자료, 패킷 캡처 파일은 이 저장소에 포함하지 않습니다.
